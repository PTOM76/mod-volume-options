# Mod Sound Volume Options
## English
If you install this, you can change the volume of sounds added by mods.  
Industrial mods can be especially noisy, so we created this to solve that problem.

Required mods (for using the GUI): [MCPitanLib](https://www.curseforge.com/minecraft/mc-mods/mcpitanlibarch), [Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api)
(When using on Fabric Loader, [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api) is also required)  
Mod Loader: Fabric Loader, Minecraft Forge Loader, NeoForge Loader  
License: MIT License  
Modpack: Useable

If MCPitanLib is not installed, the GUI cannot be used, but it is still possible to manually configure the settings by editing `config/mod_volume_options.json`.

## 日本語
追加したmodごとに音量を変更できるmodです。
特に音がうるさい工業系MODで音量を小さくしたかったので作りました。

前提MOD (GUI利用時)： [MCPitanLib](https://www.curseforge.com/minecraft/mc-mods/mcpitanlibarch), [Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api)
(Fabric Loaderでは、[Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)も必要)
MOD Loader： Fabric Loader、Minecraft Forge Loader、NeoForge Loader
ライセンス： MIT
Modpack： OK

MCPitanLibが入っていない場合はGUIは使えませんが、`config/mod_volume_options.json`を編集することで手動で設定を変更することは可能です。
